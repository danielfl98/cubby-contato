# Cubby — contato

Este espaço é para **adultos** (pais, responsáveis e professores) enviarem dúvidas, sugestões e relatos de problemas sobre o [Cubby](https://cubby.orkae.com.br), site de jogos educativos para crianças.

## ⚠️ Não poste dados de crianças

Este repositório é **público**: tudo o que for escrito aqui pode ser lido por qualquer pessoa.
Não informe nome, idade, foto, escola, localização, e-mail ou qualquer dado de crianças. Se precisar descrever um problema, fale só do que aconteceu no jogo (ex.: "o jogo da memória travou no nível 2").

## Como falar com a gente

Abra uma [Issue](../../issues/new) com um título curto e a descrição do que você viu ou sugere. Para problemas, ajuda dizer o aparelho e o navegador (ex.: "Android, Chrome").

O Cubby não coleta dados pessoais; veja a [Política de Privacidade](https://cubby.orkae.com.br/privacidade).
